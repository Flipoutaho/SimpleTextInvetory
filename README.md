실행 파일 : SimpleTextInvetory.exe

메뉴에 표시되는 항목 중 원하는 번호를 입력 후 엔터
아이템 획득(ID는 우측 참조)
	  EX1)	‘1’ 입력  >  ‘1’ 입력  > 임의의 랜덤한 아이템 획득
	  EX2) ‘1’ 입력  >  ‘2’ 입력  > “10001” 입력  >  원하는 아이템 획득
아이템 사용
	  EX) ‘2’ 입력 > 사용(장착)원하는 아이템 문자 입력(a ~ p) >  장비/시스템 메시지 확인
아이템 위치 변경
	  EX) ‘3’ 입력 > 위치 변경을 원하는 아이템 문자 2개 입력(a ~ p) >  장비/시스템 메시지 확인
아이템 버리기
	  EX) ‘4’ 입력 > 버리기 원하는 아이템 입력(a ~ p) >  인벤토리/시스템 메시지 확인
슬롯 확장
	  EX) ‘5’ 입력 > 시스템 메시지 확인
장비 해제
	  EX) ‘6’ 입력 > 장비 해제 부위 입력(1 ~ 3) >  인벤토리/장비/시스템 메시지 확인
